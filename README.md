# Examen Final - Programación II

**Estudiante:** Johany Paola Vásquez Alfaro

## Descripción
Aplicación móvil desarrollada con React Native,
Expo y TypeScript para autenticación de usuarios
y gestión de fotografías.

## Funcionalidades
- Inicio de sesión mediante Supabase.
- Persistencia de sesión.
- Cierre de sesión.
- Selección de fotografías desde la galería.
- Captura de fotografías mediante la cámara.
- Vista previa, cambio y eliminación de fotografías.

## Tecnologías
- React Native
- Expo
- TypeScript
- Supabase Auth
- AsyncStorage
- Expo Image Picker

## Instalación
1. Clonar el repositorio.
2. Ejecutar npm install.
3. Configurar la URL y clave pública de Supabase.
4. Ejecutar npx expo start.
5. Abrir la aplicación mediante Expo Go.
